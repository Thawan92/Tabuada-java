# Gerador de Tabuada em Java

Aplicação desenvolvida em Java para praticar lógica de programação, entrada de dados pelo console e estruturas de repetição. O programa solicita um número ao usuário e exibe a sua respectiva tabuada de multiplicação de 0 a 10.

## Funcionalidades
* Leitura de dados via console utilizando a classe `Scanner`
* Cálculo automático de multiplicação com laço de repetição (`for`)
* Exibição formatada dos resultados no terminal

## Tecnologias utilizadas
* Java
